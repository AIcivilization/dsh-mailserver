# dsh-mailserver

> npm 名称占位版本 `0.0.1`。功能尚未实现，此版本仅用于锁定包名。

Deploy and manage a self-hosted mail server on a VPS from DeepSeek Harness (Postfix, Dovecot, DKIM/SPF/DMARC, MX). 在 VPS 上自建邮箱系统。

## 状态

- 仓库：https://github.com/AIcivilization/dsh-mailserver
- 正式功能开发中；完成后会发布 `0.1.0` 及以后的真实版本。

## 安装（占位版）

```bash
dsh plugin --profile web add dsh-mailserver
```
